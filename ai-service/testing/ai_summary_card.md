# Project Overview

This project is an AI-powered compliance management backend system developed using Flask, Groq API, ChromaDB, Redis caching, and Retrieval-Augmented Generation (RAG).

The system helps manage compliance-related queries, report generation, monitoring, and health tracking through AI-powered APIs.

---

# AI Endpoints

| Endpoint | Purpose |
|----------|---------|
| /query | AI-powered compliance query handling |
| /health | System health and cache monitoring |
| /generate-report | Async AI report generation |
| /report-status | Report job status tracking |
| AI Fallback | Handles AI service failures |
| Redis Cache | Improves repeated response performance |
