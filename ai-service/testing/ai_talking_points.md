# AI Talking Points Card

## Groq API

Groq API is used to generate fast AI responses using large language models. It powers the chatbot responses and AI report generation features in the project.

---

## RAG (Retrieval-Augmented Generation)

RAG improves AI responses by retrieving relevant information from stored documents before generating answers. This helps the AI provide more accurate and context-aware responses.

---

## ChromaDB

ChromaDB is a vector database used to store embeddings and perform semantic similarity searches. It helps retrieve relevant compliance-related information during AI queries.

---

## Prompt Engineering

Prompt engineering is the process of designing effective prompts to improve AI response quality, clarity, and contextual understanding.

---

## Redis Cache

Redis cache stores repeated API responses temporarily to improve performance and reduce repeated AI processing time.

---

## Async Processing

Async processing allows report generation to happen in the background while immediately returning a job ID to the user.

---

## Flask Backend

Flask is used to build REST APIs and manage backend communication between AI services, databases, and client requests.
